# Data Job Market Analysis (SQL, Excel, Power BI)

# Introduction
A three-part analysis of the data analyst job market, using job posting data from Luke Barousse's SQL, Excel, and Power BI courses. Each folder covers one tool and answers the questions with that tool.

**Dataset credit:** The job posting data and project structure are from [Luke Barousse's course](https://github.com/lukebarousse). My work covers the queries, dashboards, and analysis.
