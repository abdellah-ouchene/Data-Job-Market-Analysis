## Introduction 
Understanding the data job market requires analyzing job demand, salary trends, and the skills employers are looking for. This project uses Power BI to explore 2024 data science job postings and **provide actionable insights for aspiring data analysts and other data professionals.**

**Following Luke Barousse's Power BI tutorial**, I recreated this interactive dashboard to develop my skills in data cleaning, data modeling, DAX, and data visualization. The dashboard brings key labor market metrics together on a single page, making it easier to explore job opportunities and compensation trends.

## Skills demonstrated 

- **Dashboard Design:** Designing a clear, intuitive, single-page dashboard to communicate key labor market insights.
- **Power Query ETL:** Cleaning, transforming, and preparing job posting data for analysis.
- **Data Modeling:** Establishing data relationships and applying Star Schema principles where appropriate.
- **DAX:** Creating measures and calculations for KPIs, salary analysis, and skill popularity.
- **Data Visualization:** Using bar charts and KPI cards to compare salaries, highlight in-demand skills, and summarize key metrics.
- **Interactive Features:** Implementing slicers, buttons, and toggle options to enable dynamic filtering and alternative report views.

## Dashboard Overview
The dashboard provides an interactive overview of the data job market to help aspiring data analysts understand in-demand skills and salary trends.


![Dashboard Page](/Images/Project%202.PNG)


The dashboard provides an overview of key metrics, including Job Count, Skills Per Job, Median Yearly Salary, and Median Hourly Salary. It also features a Skill Popularity chart that ranks the most skills, with options to switch between job percentage and job count.

The Job Salaries chart allows users to examine median salary for the selected job title, with options to switch between yearly and hourly salaries. Interactive Job Title and Country slicers enable users to filter the results based on their interests, while the Clear Slicers button makes it easy to reset the selected filters.

Together, these features provide a concise, interactive overview of job demand, technical skills, and salary benchmarks in the data job market.


## Conclusion

This project demonstrates how Power BI can transform job posting data into an interactive dashboard for exploring employment trends, in-demand technical skills, and salary benchmarks.
