This project explores the data analyst job market, focusing on top-paying roles, in-demand skills, and where high demand meets high salary.

# Background

I wanted to navigate the data analyst job market more effectively by finding out which skills pay the most and which are in demand, so I could focus my learning and job search on the right areas.

The questions this project answers follow Luke Barousse's SQL course project:
- What are the top-paying data analyst jobs?
- What skills are required for these top-paying jobs?
- What skills are most in demand for data analysts?
- Which skills are associated with higher salaries?
- What are the most optimal skills to learn?

## Tools I Used
